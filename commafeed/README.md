# Vaultwarden Password Manager

Commafeed is an simple RSS Web Reader.

```
.
└── commafeed/
    ├── data/
    ├── .env
    └── docker-compose.yaml
```

A .env File is needed with the following content:

```
DOMAIN=example.com
```
All that's left to do then is the account creation and then you are good to go.
