# FREDY

Fredy keeps searching for new apartments, houses, and flats in Europe on platforms like ImmoScout24, Immowelt, eBay Kleinanzeigen and instantly delivers the results to you via Slack, Telegram, Email, Discord or ntfy, so you can focus on the more important things in life ;)

```
.
└── fredy/
    ├── conf/
    ├── db/
    ├── .env
    └── docker-compose.yaml
```

A .env File is needed with the following contents:

```
DOMAIN=example.com
```

After that just create a account.
